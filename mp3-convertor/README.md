# YouTube 转 MP3

在 macOS 上安装 Homebrew 依赖后，从仓库根目录启动服务。

```sh
brew install yt-dlp ffmpeg deno
python3 mp3-convertor/server.py
```

打开 <http://127.0.0.1:8765/mp3-convertor/>。如果端口已被占用，可以传入 `--port 8766` 并打开程序打印的网址。按 `Ctrl+C` 停止服务。

需要 Python 3.9 或更高版本。转换在本机运行，一次处理一个单独视频，支持常规链接、分享链接和 Shorts。服务只监听本机地址，转换结束后清理临时文件。GitHub Pages 的静态托管无法执行转换服务。

## 本机 RSS

转换页支持一次粘贴最多 20 个不同的视频，包括多行链接、Markdown 链接和从网页复制的超链接文本。转换后，结果会显示 MP3 文件名和时长，可以逐条改名或从本批移除。

点击「下载」可下载当前列表。单条下载 MP3，多条下载 ZIP。点击「加入 RSS」才会更新 <http://127.0.0.1:8765/feed.xml>。同一视频只保留一个条目，更新名称会保留原来的 GUID 和发布日期。未加入 RSS 的结果为临时文件，服务停止后会清理。

节目数据库和 MP3 保存在 `mp3-convertor/data/`，也可用 `--data-dir` 指定目录。备份或迁移时请先停止服务，再复制整个数据目录。当前订阅地址只在运行转换器的电脑上可用。迁到 NAS 后需要按其网络和访问方式配置订阅地址。
